# Sifa GTPL

Dataset of cumulative paid claims for a medium italian company in the
line of business: general third party liability.

## Usage

``` r
sifa.gtpl
```

## Format

Run-off triangle with 12 development periods.

## References

Savelli, Nino, and Clemente, Gian Paolo. "Lezioni di matematica
attuariale delle assicurazioni danni." EDUCatt-Ente per il diritto allo
studio universitario dell'Università Cattolica, 2014
